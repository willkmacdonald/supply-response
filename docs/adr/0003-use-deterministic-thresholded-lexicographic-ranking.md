# Keep decision authority deterministic and use thresholded lexicographic ranking

Deterministic services own arithmetic, feasibility, Approval Satisfaction, comparator values, and recommendation inputs; agents retrieve, normalize, summarize, and explain those typed results. Feasible Response Options are ranked through ordered materiality thresholds instead of a weighted score or pure lexicographic comparison. This sacrifices a single compact score and some agent flexibility for reproducibility, visible business priorities, and the ability to treat immaterial differences as ties.
