# Map portable Demo Personas to tenant identities

The domain uses stable fictional persona IDs for Alex, Jordan, and Taylor while each deployment binds them to tenant-specific Entra object IDs, UPNs, and app roles. Finance is satisfied through Taylor's scoped Standing Authorization and an analysis-bound Approval Satisfaction rather than a live presentation-time interaction. This adds explicit binding and approval records but allows the demo to move between tenants without rewriting domain history or requiring an additional Teams license for Taylor.
